# Spec Project Case File

A responsive, self-contained portfolio case study for **The Independent Expert**.

## View

Open `index.html` directly in a browser. No build step or external assets are required.

## Included

- Editorial navy, gold and ivory visual system
- 13-section case-file narrative
- Responsive desktop/mobile layouts
- Interactive case index with active-section states
- Reading progress indicator
- Scroll-reveal motion with reduced-motion support
- Print-friendly styling
- Accessible semantic structure

## Customise

All brand tokens are at the top of `index.html` under `:root`. The page uses system font stacks so it remains fully self-contained. Replace the `CF / Strategic Casework` wordmark and footer copy with the portfolio owner's name when integrating it into the main site.
